# Task

This repository contains a JavaScript solution that:
1. Takes a dictionary where keys are dates (`YYYY-MM-DD`) and values are integers.
2. Returns a dictionary where keys are weekdays (`Mon, Tue, ... Sun`) and values are the sum of integers for that day.
3. If a weekday is missing, its value is calculated as the mean of the previous and next available weekday values.
